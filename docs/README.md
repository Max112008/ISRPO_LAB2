## Описание модулей

Библиотека `geometric_lib` предназначена для вычисления площадей и периметров базовых геометрических фигур. Каждый модуль отвечает за отдельную фигуру:

* **rectangle.py** — прямоугольник: вычисление площади (`a * b`) и периметра (`2 * (a + b)`).
* **circle.py** — круг: вычисление площади (`pi * r * r`) и длины окружности (`2 * pi * r`) с использованием модуля `math`.
* **triangle.py** — треугольник: вычисление площади по основанию и высоте (`a * h / 2`) и периметра по трем сторонам (`a + b + c`).
* **square.py** — квадрат: вычисление площади (`a * a`) и периметра (`4 * a`).

## Описание каждой функции с примерами вызова

### 1. rectangle.py

#### `area(a, b)`
* **Описание:** принимает два числа — длины сторон прямоугольника.
* **Возвращает:** площадь прямоугольника (`a * b`).
* **Пример вызова:**
```python
import rectangle

s = rectangle.area(4, 7)
print(s)  # Выведет: 28
```

#### `perimeter(a, b)`
* **Описание:** принимает два числа — длины сторон прямоугольника.
* **Возвращает:** периметр прямоугольника (`2 * (a + b)`).
* **Пример вызова:**
```python
import rectangle

p = rectangle.perimeter(4, 7)
print(p)  # Выведет: 22
```

---

### 2. circle.py

#### `area(r)`
* **Описание:** принимает число — радиус круга.
* **Возвращает:** площадь круга (`pi * r * r`).
* **Пример вызова:**
```python
import circle

s = circle.area(5)
print(s)  # Выведет: 78.53981633974483
```

#### `perimeter(r)`
* **Описание:** принимает число — радиус окружности.
* **Возвращает:** длину окружности (`2 * pi * r`).
* **Пример вызова:**
```python
import circle

p = circle.perimeter(5)
print(p)  # Выведет: 31.41592653589793
```

---

### 3. triangle.py

#### `area(a, h)`
* **Описание:** принимает два числа — сторону треугольника и высоту, опущенную на нее.
* **Возвращает:** площадь треугольника (`a * h / 2`).
* **Пример вызова:**
```python
import triangle

s = triangle.area(6, 4)
print(s)  # Выведет: 12.0
```

#### `perimeter(a, b, c)`
* **Описание:** принимает три числа — длины трех сторон треугольника.
* **Возвращает:** периметр треугольника (`a + b + c`).
* **Пример вызова:**
```python
import triangle

p = triangle.perimeter(3, 4, 5)
print(p)  # Выведет: 12
```

---

### 4. square.py

#### `area(a)`
* **Описание:** принимает число — длину стороны квадрата.
* **Возвращает:** площадь квадрата (`a * a`).
* **Пример вызова:**
```python
import square

s = square.area(5)
print(s)  # Выведет: 25
```

#### `perimeter(a)`
* **Описание:** принимает число — длину стороны квадрата.
* **Возвращает:** периметр квадрата (`4 * a`).
* **Пример вызова:**
```python
import square

p = square.perimeter(5)
print(p)  # Выведет: 20
```
